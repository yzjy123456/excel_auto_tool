# Excel 批量数据清洗与报表生成工具

一个**批量处理 Excel 表格**的命令行小工具：把指定文件夹里的多张 `.xlsx` 一键清洗、合并、分组统计，自动生成清洗明细表和汇总报表。无需懂代码，改配置即可用，适合行政、运营、市场等日常处理表格的重复工作。

> 目标：用最简单的方式解决"一堆表格要整理、要汇总"的痛点。

---

## 功能特性

- ✅ **批量读取**：自动扫描 `input/` 文件夹下所有 `.xlsx`，多表合并
- ✅ **数据清洗**（规则可配置）：
  - 删除全空行
  - 指定列去重
  - 空值智能填充：文本列填"未知"、数值列填 0（避免类型混乱导致求和报错）
  - 文本首尾空格清理
- ✅ **分组统计**：按任意列分组，输出每组记录数与数值总和
- ✅ **双输出**：`cleaned_data.xlsx`（清洗明细）+ `summary_report.xlsx`（汇总报表）
- ✅ **稳健容错**：单个文件读取失败不会中断整个程序，日志清晰记录
- ✅ **零代码配置**：所有规则在 `config.py` 修改，不用动业务代码

## 快速开始

### 环境要求
- Python 3.9+
- 依赖：`pandas`、`openpyxl`

### 安装依赖
```bash
cd excel_auto_tool
pip install -r requirements.txt
```

### 运行
```bash
python main.py
```

### 三步使用流程
1. 把待处理表格放进 `input/` 文件夹（表头保持一致）
2. 按需修改 `config.py` 中的表头名和规则
3. 运行 `python main.py`，去 `output/` 查看两份结果

## 配置说明（config.py）

| 配置项 | 示例值 | 说明 |
|---|---|---|
| `INPUT_FOLDER` | `./input` | 输入文件夹路径 |
| `OUTPUT_FOLDER` | `./output` | 输出文件夹路径 |
| `DROP_EMPTY_ROW` | `True` | 是否删除全空行 |
| `DROP_DUPLICATE_COL` | `"name"` | 按哪一列去重，不需要填 `None` |
| `FILL_NA_METHOD` | `"unknown"` | 空值处理：`zero` / `unknown` / `drop` |
| `TRIM_STR` | `True` | 文本是否去除首尾空格 |
| `GROUP_BY_COL` | `"department"` | 按哪一列分组统计 |
| `SUM_COL` | `"amount"` | 需要求和的列 |

> 表头名必须与你的真实表格一致，否则统计会跳过并提示。

## 常见问题 / 踩坑记录

**Q：汇总报表求和报错 `unsupported operand type(s) for +: 'float' and 'str'`？**
A：空值填充把字符串"未知"填进了数值列，导致列类型混乱。本项目已修复——空值按列类型填充：数值列填 0、文本列填"未知"，可放心求和。

**Q：`input/` 里没有文件？**
A：程序会提示并安全退出，不会报错。

**Q：某个文件读不出来会怎样？**
A：只跳过该文件并记录错误日志，不影响其他文件处理。
